
# Week 4 — JavaScript Logic Challenges

**Course:** Advanced Frontend Web Development  
**Runtime:** Node.js  
**Language:** Plain JavaScript

## Overview

This repository contains my solutions to the Week 4 JavaScript logic challenges. The exercises practise variables, conditions, loops, functions, strings, numbers, and problem-solving.

## Technologies and rules

- Plain JavaScript executed with Node.js.
- Pseudocode comments before every challenge solution.
- At least three tests per function, including edge cases.
- Loops instead of `map`, `filter`, and `reduce`.
- Comments comparing readable and concise approaches.
- One JavaScript file per round.
